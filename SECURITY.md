# Security and privacy / 安全与隐私

PhotoNaming 1.0.x operates on local filesystem names and keeps rename history
on your Mac. It does not upload files, read image pixels, or send telemetry.
History includes full paths, so treat it as private data.

For a security concern, use [GitHub private vulnerability reporting](https://github.com/QiushanHuang/PhotoNaming/security/advisories/new)
when available. Otherwise open an issue asking for a private contact without
including exploit details or private paths. Supported fixes target the latest
release; there is no guaranteed response time.

Release apps are ad-hoc signed and **not Apple-notarized**. Checksums detect
download corruption; they are not a substitute for trusting the release source.
Use the official release page. Do not disable Gatekeeper globally.

---

PhotoNaming 1.0.x 在本机处理名称并保存改名记录，不上传文件、不读取图片像素，
也不发送遥测。历史记录包含完整路径，应视为私人数据。

安全问题优先使用 GitHub 私密漏洞报告；若不可用，请先开 Issue 请求私下联系，
不要公开利用细节或私人路径。修复以最新版本为目标，不承诺固定响应时间。

发布的应用使用本地临时签名，**未经 Apple 公证**。校验和用于检测下载损坏，
不替代对来源的判断。仅从官方发布页下载，不要全局关闭 Gatekeeper。
