# PhotoNaming 1.0.0 / 照片命名

The first public release: a native macOS workbench for checking, editing and
confirming photo-folder and file names. Created and maintained by
[Qiushan (@QiushanHuang)](https://github.com/QiushanHuang).

## Downloads

- `PhotoNaming-1.0.0-macos-arm64.dmg` — drag the app to Applications.
- `PhotoNaming-1.0.0-macos-arm64.zip` — portable archive with the same app.
- `SHA256SUMS.txt` — SHA-256 checksums for both archives.
- `BUILD-INFO.txt` — version, source revision, architecture and build-tool information.
- GitHub's source archives and the `v1.0.0` tag contain the source, tests and documentation.

Both binary packages include the app, offline English/Chinese instructions and
MIT license. Requires **Apple Silicon, macOS 14+**. The interface is Chinese;
the README and full user guide are bilingual, with same-page language links.

## Included

Grouped original-state and parsing columns; compliant/non-compliant filters;
six editable fields; selective batch assignment; explicit preview and confirmation;
no-overwrite renaming; source/parent identity checks; persistent undo and per-item
failure reports. The new logo is used in the app, Dock icon and documentation.

Debug and optimized-release tests cover dates, Unicode, optional-field positions,
extensions, conflicts, external replacements, nested renames, partial failure,
logging and recovery. Native UI checks have exercised import, editing, batch
assignment, preview, actual rename, reparse and undo with synthetic fixtures.

## Signing and limits

**Ad-hoc signed; not Developer ID signed or Apple-notarized.** For a verified
release blocked at first launch, use [Apple's per-app Open Anyway flow](https://support.apple.com/102445).
No global security changes are needed. Intel binaries, cloud/network drive
validation, large-collection stress testing and real drag-gesture validation are
not part of this release. Unsubmitted drafts are not persisted across sessions.
