# PhotoNaming 1.1.0 — 更新说明 / Update notes

## 中文

1.1.0 更新了界面与操作流程，并加入独立的照片和视频时间编辑。此文件记录源码和本机安装版本的变化；截至 2026-10-28，GitHub 最新公开发布版仍是 1.0.0。

- 主窗口精简说明文字，按导入、筛选、编辑和预览安排操作；开始编辑字段时会选中对应行，批量赋值只启用已勾选的字段。
- 表格支持窄窗口和深色外观。改名预览、结果和撤销清单显示实际文件名与路径，包括下划线。
- 时间编辑支持统一时间、按差值平移、参考照片校准，以及将文件时间同步到各自的拍摄时间。可选择字段和时区，逐项预览并核验结果。
- 时间设置改变后需要重新预览。确认写入前会说明：时间修改无法撤销，不保留长期媒体备份，也可能影响先前改名的撤销。

时间编辑在本机运行，使用随包附带的 ExifTool；日志和改名历史分开。媒体写入采用临时副本与核验，exFAT 上使用可恢复的分步替换。批量操作可能部分成功，请检查逐项结果；处理重要文件前应自行保留备份。

支持 Apple Silicon、macOS 14 或更新版本。已运行调试与 Release 测试，并使用隔离样本检查界面、预览、时间写入、改名和撤销。Intel、网络/云挂载盘、大规模集合及真实拖拽手势尚未完整验证。构建为临时签名，未经 Apple 公证。

## English

Version 1.1.0 streamlines the interface and adds an independent photo/video time editor. These notes describe the source and local installation; as of 2026-10-28, the latest published GitHub release remains 1.0.0.

- The main window groups import, filtering, editing and preview. Starting to edit a field selects its row; batch inputs are enabled only when checked.
- The table adapts to narrower windows and dark appearance. Rename previews, results and undo lists show actual names and paths, including underscores.
- Time editing can set a common time, shift by an offset, calculate an offset from a reference photo, or synchronize filesystem times to each file's capture time. Choose fields and timezone, then review and verify per-file results.
- Changing time settings requires a new preview. Before writing, the app states that time edits cannot be undone, no permanent media backup is kept, and earlier rename undo records may be affected.

Time editing runs locally with bundled ExifTool and separate logs. Media writes use verified temporary copies; exFAT uses recoverable staged replacement. A batch can partially succeed, so review individual results and keep your own backup of important files.

Requires Apple Silicon and macOS 14 or later. Debug and Release tests passed, and isolated samples were used to check the interface, previews, time writes, renames and undo. Intel, network/cloud volumes, large collections and real drag gestures have not been fully verified. The build is ad-hoc signed and is not Apple-notarized.
