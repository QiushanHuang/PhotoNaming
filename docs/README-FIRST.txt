PhotoNaming 1.0.0 / 照片命名
Created and maintained by Qiushan (@QiushanHuang)
https://github.com/QiushanHuang/PhotoNaming

ENGLISH
Requires an Apple Silicon Mac with macOS 14 or later.
Move 照片命名.app to Applications or a folder you own and open it.
The app is ad-hoc signed and NOT Apple-notarized. If the verified official
release is blocked, follow Apple's per-app Open Anyway instructions:
https://support.apple.com/102445
Do not disable Gatekeeper globally.

Choose files/folders → filter non-compliant names → edit date/title fields →
select rows → Preview → Confirm and rename. No file changes happen before
confirmation. The app interface is Chinese; USER_GUIDE.md explains every step
in English and Chinese. Undo last rename restores names if paths are unchanged
and destinations are free. Unsubmitted edits do not survive closing the app.

中文
需要 macOS 14 及以上的 Apple Silicon Mac。
将「照片命名.app」放入应用程序或自己有权限的目录后打开。
本包为临时签名、未经 Apple 公证；确认官方来源后，如首次启动被拦截，
按 Apple 官方说明使用「系统设置 → 隐私与安全性 → 仍要打开」。
不要全局关闭 Gatekeeper。

选择文件/文件夹 → 筛选未符合 → 填写日期与标题 → 选中行 → 预览 → 确认改名。
确认前不修改文件。完整说明见 USER_GUIDE.md。路径未变且无同名冲突时可撤销。
未提交草稿在关闭后不会保留。

Release checksums / 安装包校验和：
Download SHA256SUMS.txt from the same GitHub release and compare using shasum.
从同一 GitHub Release 下载 SHA256SUMS.txt，使用 shasum 校验。
