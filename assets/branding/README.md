# PhotoNaming identity

The mark combines a blue folder, an ivory naming label and a teal checkmark:
**a folder with a clear, confirmed name**. A dark rounded-square tile keeps the
silhouette readable in the macOS Dock and on light or dark repository pages.

`logo.png` is the original transparent 1254 × 1254 raster artwork. It is used
in the README and app header; `scripts/build-icon.sh` derives the standard
16–1024 px icon representations and an `.icns` file for the application bundle.
Artwork and software are included under the project's MIT license.

Creator / maintainer: [Qiushan (@QiushanHuang)](https://github.com/QiushanHuang).
Generation used the **built-in image generation tool**, not an external CLI.
No existing third-party logo was supplied as a reference.

## Generation brief

> Use case: logo-brand. Create the final production application icon for PhotoNaming, a polished native macOS utility for organizing and safely renaming photographs and folders. One single iconic mark, square 1024x1024 output. A distinctive softly rounded indigo-blue folder integrated with a clean ivory naming label; the label's right edge resolves into a small confident teal checkmark. The idea is an organized photo folder receiving its correct name. Restrained premium macOS icon craft, precise geometric silhouette, subtle dimensional paper layering and gentle controlled lighting, nearly flat, not glossy plastic. Strong recognizability at 32px, generous deliberate negative space, only 2-3 large shapes, no fine detail. Centered on a deep midnight-navy rounded-square tile with balanced corner radius and large safe margins. Transparent outside the rounded-square tile, no surrounding white canvas, no mockup scene. No words, letters, numbers, watermark, camera lens, sparkles, busy scenery, or multiple variants. The logo must stand alone on both light and dark README backgrounds and as a Dock icon.

The requested output was 1024 px; the tool returned 1254 px. The returned artwork
is preserved, and icon-size derivation is performed during packaging.
